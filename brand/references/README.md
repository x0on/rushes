# Rushes — brand handoff

## Approved direction

Rushes is an open-source media manager for professional production work: video, photography, and audio. Its audience includes filmmakers, photographers, independent creators, and production teams managing shoots, projects, and substantial archives. It should feel approachable and professional, not like a personal phone-photo gallery.

The chosen logo is **01 / Together**, the LEFTMOST mark in both reference images: layered upright files forming an R. The chosen color scheme is **01 / Ocean**, also the LEFTMOST column. The other concepts are not selected.

## Approved public copy

**Your shoots. Your projects. One organized system.**

Rushes is an open-source media manager for filmmakers, photographers, and production teams. Find video, photos, and audio, bring in new shoots, and keep your archive organized—on storage you control.

Avoid the previous headline “All your media. One place.” It suggests consumer photo storage. The reference image still contains that old headline; replace it with the approved copy above.

## Ocean palette

| Role | Color | Hex |
| --- | --- | --- |
| Signature / primary action | Ocean teal | #007F78 |
| Soft highlight / light selected background | Pale mint | #DDF4EF |
| Light page background | Paper | #F7FAF9 |
| Primary text / dark page background | Deep ink | #132B2A |
| Raised dark surface | Dark teal | #1E3937 |

Use teal for the logo, primary buttons, focus accents, and selected navigation. Keep large working surfaces neutral so footage and photographs remain the focus. Use deep ink text on light surfaces, and paper or pale mint text on dark surfaces. White (#FFFFFF) is available for inverse logo and button text.

In dark mode, use pale mint for small accent text and icons rather than assuming the primary teal is readable on a dark surface. Validate actual text, controls, focus indicators, and disabled states for accessibility during implementation. Do not rely on color alone for statuses. Semantic success, warning, and error colors have not yet been selected.

## Visual and interface direction

- Simple, clear layouts with restrained color and readable type.
- Show real professional context: event names, shoot dates, clip details, project folders, and video/audio/still assets from the same shoot.
- Search results should reflect shoots and events, not just a consumer photo grid.
- The original product concept has Search, Ingest, and a separate Manage area. Reference mockup navigation is illustrative, not an approved feature specification.
- Preserve the chosen layered R silhouette. Keep a black version and a white inverse version in addition to Ocean teal.
- Refine and test the logo at small sizes before using it as a favicon or app icon.
- No exact font family has been selected. The reference suggests a clean contemporary sans serif.

## Product context

Cross-platform software intended for Mac, Windows, and compatible network storage. Media stays on the user's storage. No user accounts are intended; an installer/owner-created local admin password protects administrative file-management actions. Do not describe this as “no passwords.” Verify implementation details and platform support separately before publishing download or compatibility claims.
