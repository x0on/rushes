# Visual assets

Two original AI-generated editorial illustrations were created with the built-in image generation tool. They illustrate archive stewardship and human-directed production; neither depicts actual customers, staff, or a verified StoryTown interface. JPEG versions are optimized for the website; PNG files are local originals.

`rushes-interface.png` is copied unchanged from `docs/assets/interface.png` in x0on/rushes at commit 05779da523b5e72f68cd03080d6fc1160275fe86. The original website describes it as an interface concept in development; both language versions retain that qualification. The visible interface text in this reused source remains English.

## Archive illustration prompt

Use case: photorealistic-natural. Asset type: institutional audiovisual consultancy website editorial image, landscape 3:2. Primary request: professional institutional audiovisual archive brought to life. A senior female film archivist and male video editor reviewing photographic contact sheets and a hard drive beside a professional editing monitor in a modest beautiful municipal audiovisual studio. Monitor displays a generic grid of old city cultural festival footage, not a branded interface. Documentary photography, natural window light, cinematic yet believable, muted deep teal, sage green, silver, warm skin tones. Authentic human collaboration, archival materials carefully handled. Beautiful restrained composition, tactile surfaces, people directing technology. No readable text, logos, watermarks, sci-fi, robots, or fantastical holograms.

## Creative production illustration prompt

Use case: photorealistic-natural. Asset type: institutional audiovisual consultancy website case-study visual, wide landscape 3:2. No readable text, logos, watermarks, robots, automation fantasy, or stock-photo handshake.
